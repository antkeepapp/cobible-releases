## 💡 First-Launch Notes (Self-Signed / Unsigned Binaries)

Until CoBible is published on the official Apple App Store and Google Play, install packages are distributed directly:

* **Windows (SmartScreen):**  
  If Windows displays *"Windows protected your PC"*:  
  Click **"More info"** ➔ **"Run anyway"**.

* **macOS (Gatekeeper):**  
  If macOS warns that the app cannot be opened because developer cannot be verified:  
  Open **System Settings** ➔ **Privacy & Security** ➔ scroll down and click **"Open Anyway"**.

* **Android:**  
  When prompted during install, allow **"Install unknown apps"** for your browser or file manager.

## ✨ Key Features

* 📖 **Smart Bible Reader:** Instant full-text search across 31,000+ verses, footnotes, cross-references, bookmarks, and Daily Verse.
* 🤖 **AI Study Companion (Gemini AI):** In-depth chapter Q&A, contextual verse research, and historical context.
* 🎧 **Audio Podcasts:** Background playback with dedicated mini-player and rich study topics.
* 📅 **Reading Plans:** Chronological, sequential, and topical plans with habit tracking and reading streak.
* 🔄 **Built-in Auto-Updates:** Informs you as soon as a new version is available.
